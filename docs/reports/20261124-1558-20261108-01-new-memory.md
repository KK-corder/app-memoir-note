## ブリーフとの差異・仮定

- 場所の `/` は、metaの欄を壊さないよう理由を出して拒否します。
- 下書きはデモ／Driveの置き場別に保存。入力中の名前は札への追加を促します。
- 拒否されたノートは追記・写真も止め、理由を端末に保持します。
- 写真は選択時に縮小し、メモリ内だけに保持。受付後の送信は画面移動後も続けます。

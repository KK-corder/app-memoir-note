## ブリーフとの差異・仮定

- 場所の `/` は、3行目を3欄に保ち、候補の解析を壊さないよう理由を出して拒否します（項目表には明記なし）。
- 下書きは既存キー内でデモ／Driveの置き場ごとに分けます。入力中で札にしていない名前も保存し、作成時は「人を足す」で確定するよう案内します。
- 拒否された作成記録は追記・写真も止めます。rejectedは直近50件なので、受け取った理由を端末に保持し、後の書き出しから理由が消えても復旧操作を残します。
- 写真は選択時に既存の縮小処理でJPEGへ変換し、メモリ内だけに保持します。作成受付後は、画面を移動しても受け付けた送信を続けます。
- 依存追加・ネットワークアクセス・ブラウザ起動・ファイル削除・コミット・pushは行っていません。`_TODO.md`は変更していません。

# 設計判断の記録

あとから「なぜこうなっているか」を、別のセッションや別のエージェントが再検討せずに済むように残す。
書くのは、選択肢があって1つに決めたことだけ（実装の細部は書かない）。新しいものを上に追記する。

書き方:

```
## YYYY-MM-DD <決めたこと>
- 決定: 
- 理由: 
- 却下した案: （あれば、なぜ却下したか）
- 決めた人: ユーザー / Claude（ユーザー確認済み）
```
